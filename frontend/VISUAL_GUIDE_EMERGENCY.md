## Color Scheme

### Primary Colors
- Purple: `#667eea` (Main actions, links)
- Dark Purple: `#764ba2` (Hover states, accents)
- Pink: `#e84393` (Secondary highlight)

### Alert Colors
- Success Green: `#3c3` (Green for success)
- Error Red: `#c33` (Red for errors)
- Info Blue: `#1976d2` (Edit buttons)

### Neutral Colors
- Background: `#f5f7fa` (Light gray-blue)
- Card Background: `white`
- Text: `#333` (Dark gray)
- Border: `#e0e0e0` (Light gray)

## Responsive Breakpoints

### Desktop (1200px+)
- 3-column contact grid
- Full form width
- Standard navbar

### Tablet (768px - 1199px)
- 2-column contact grid
- Wider padding
- Responsive form

### Mobile (320px - 767px)
- 1-column contact grid
- Full-width form
- Hamburger menu navigation
- Stacked buttons

## Accessibility Features

### Visual
- Clear contrast ratios (WCAG AA compliant)
- Icons + text combinations
- Color-coded alerts
- Focus indicators on inputs

### Text
- Descriptive labels for all form fields
- Placeholder examples
- Error messages explain what's wrong
- Success messages confirm actions

### Interactive
- Proper tab navigation
- Keyboard navigation support
- Large touch targets on mobile
- Confirmation dialogs for destructive actions

## Animations

### Smooth Transitions
- Form slide-in: 0.3s ease
- Card hover: translateY(-5px) + shadow
- Button hover: translateY(-2px) + glow
- Progress bar: width transition 0.3s ease
- Alert messages: slide in animation

## State Indicators

### Loading States
- Currently uses synchronous operations
- No loading spinner needed
- Instant user feedback

### Empty States
- Large icon (64px) with emoji
- Descriptive heading
- Helpful subtext
- Call-to-action button

### Error States
- Red alert box with icon
- Clear error message
- Form remains open for correction
- Focus on problematic field (recommended UX)

## Print View
- Not specifically styled
- Uses default browser print styles
- Recommended: Add print styles if needed

## Dark Mode
- Currently light-themed only
- Could be extended with CSS variables
- Theme toggle recommended for future

## Internationalization (i18n)
- Currently English only
- All text strings could be moved to i18n config
- Recommended for future multi-language support
